About Me

I’m a Master’s student in Electrical and Computer Engineering at Portland State University, specializing in Embedded Systems, Firmware, and Hardware–Software co-design. I enjoy building systems from bare metal to Linux and validating them through simulation, emulation, and real hardware.

Selected Projects

Embedded Linux Firmware Bring-Up on Zynq SoC

Brought up Embedded Linux on Zynq-7000 using PetaLinux. Integrated AXI GPIO and IIC, wrote C firmware for peripheral control, debugged device-tree and kernel drivers, and validated PS–PL interfaces.

FPGA-Based Real-Time Environmental Control System

Designed a MicroBlaze-based embedded system on Nexys-A7 with FreeRTOS. Implemented I2C drivers for sensors and used PID control with PWM outputs for environmental regulation.

Smart Transit Display (Android + ESP32 + MQTT)

Built an Android app using Jetpack Compose and MVVM. Integrated TriMet APIs and MQTT communication with an ESP32 display for real-time transit information.
