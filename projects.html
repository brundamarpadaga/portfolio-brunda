Embedded Linux Bring-Up on Zynq-7000 SoC (Zybo Z7-20)

Brought up embedded Linux on Zynq-7000 using PetaLinux, integrating custom FPGA peripherals (AXI GPIO, AXI IIC) with Linux kernel drivers for LED control and an SSD1306 OLED display driven over I2C. Currently extending the same base project to bring up native PS Ethernet (GEM0) and a BME280 temperature/humidity sensor, publishing sensor data to the cloud over MQTT (HiveMQ) with TLS — all while keeping the original GPIO and I2C peripherals in place.

Technologies: Zynq-7000, PetaLinux, AXI GPIO, AXI IIC, Device Tree, C, Linux Kernel Drivers, Ethernet (GEM0/macb), MQTT (paho-mqtt-c), TLS, BME280, I2C

Key Achievements:

  • Integrated custom AXI GPIO/IIC peripherals with Linux kernel drivers, debugging device-tree and interrupt binding issues
  • Wrote an SSD1306 OLED driver from the datasheet, implementing the I2C protocol, framebuffer management, and GDDRAM addressing
  • Brought up native PS Ethernet (GEM0) via the macb driver and validated DHCP and internet connectivity end to end
  • Diagnosed a TLS handshake failure to a missing battery-backed RTC and fixed it by auto-syncing the clock via ntpdate on interface-up
  • In progress: publishing BME280 sensor readings to HiveMQ Cloud over MQTT/TLS from a custom C application

Cache-Aware Accelerator Design: ACP vs HP0 and HLS Matrix Multiply on Zynq-7020

Designed and benchmarked a cache-aware hardware accelerator on the Zybo Z7-20 (Zynq-7020), comparing the coherent ACP and non-coherent HP0 PS↔PL memory paths, then implemented a two-level tiled matrix-multiply accelerator in Vitis HLS that reads through ACP and writes through HP0 — achieving up to a 4.89× speedup over an ARM Cortex-A9 software baseline.

Technologies: Zynq-7020, Vivado, Vitis HLS, AXI DMA, ACP/HP0, ARM Cortex-A9, C, PL310 L2 Cache, ARM PMU Instrumentation

Key Achievements:

  • Benchmarked ACP vs HP0 memory paths across matrix sizes N=32–512, showing ACP is 1.5–1.9× faster due to coherent, cache-warm reads served by the Snoop Control Unit
  • Designed a two-level tiled matmul HLS kernel (FETCH_TILE=16 DDR fetch tile, TILE=4 fully-unrolled MAC engine) achieving up to 4.89× speedup over software at N=512
  • Iterated through four hardware revisions, diagnosing and resolving DSP/LUT resource tradeoffs, an AXI write/read race condition on a shared bundle, and loop-pipelining (II) violations
  • Instrumented ARM PMU and PL310 L2 cache counters to correlate cache hit rate with measured speedup
  • Documented the full design iteration history, including correctness-testing methodology and known open issues
