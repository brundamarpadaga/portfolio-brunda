Selected Projects

Embedded Linux Firmware Bring-Up on Zynq SoC

Brought up Embedded Linux on Zynq-7000 using PetaLinux. Integrated AXI GPIO and IIC, wrote C firmware for peripheral control, debugged device-tree and kernel drivers, and validated PS–PL interfaces.

Technologies: Zynq-7000, PetaLinux, AXI, Device Tree, C, Linux Kernel Drivers

Key Achievements:

  • Successfully integrated custom hardware peripherals with Linux kernel
  • Debugged and resolved device-tree configuration issues
  • Validated PS-PL data transfer interfaces

FPGA-Based Real-Time Environmental Control System

Designed a MicroBlaze-based embedded system on Nexys-A7 with FreeRTOS. Implemented I2C drivers for sensors and used PID control with PWM outputs for environmental regulation.

Technologies: MicroBlaze, Nexys-A7, FreeRTOS, I2C, PID Control, PWM, Verilog/VHDL

Key Achievements:

  • Implemented real-time task scheduling with FreeRTOS
  • Developed custom I2C drivers for sensor communication
  • Designed PID controller for precise environmental regulation

Smart Transit Display (Android + ESP32 + MQTT)

Built an Android app using Jetpack Compose and MVVM. Integrated TriMet APIs and MQTT communication with an ESP32 display for real-time transit information.

Technologies: Android, Jetpack Compose, MVVM, ESP32, MQTT, TriMet API, Kotlin/Java

Key Achievements:

  • Integrated real-time public transit APIs
  • Established reliable MQTT communication between mobile app and ESP32
  • Designed clean, modern UI with Jetpack Compose
